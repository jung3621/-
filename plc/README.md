# plc

Mitsubishi Q시리즈 PLC와 GX Works2 관련 하드웨어, 파라미터, 래더 로직, 디바이스 맵, 유지보수 절차를 둡니다. PLC 프로그램 설명은 HMI 문서와 분리하고 태그/디바이스 매핑으로 연결합니다.

## 첫 확장 순서
1. CPU·베이스·전원·I/O 모듈 구성
2. GX Works2 프로젝트/버전과 PLC 파라미터
3. 디바이스 맵과 주요 래더 네트워크 설명
4. 기동·정지·인터록·알람 로직
5. 백업·복구와 온라인 점검 절차
