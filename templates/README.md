# templates

반복해서 사용하는 프로젝트 개요, 변경 기록, 시험 결과, 통신 표, 알람 목록 양식을 둡니다.

## 첫 확장 순서
1. 문서 메타데이터 헤더
2. 프로젝트 개요
3. PLC/HMI 버전 및 변경 기록
4. 시험 결과와 결함 기록
5. 디바이스·태그·알람·통신 맵
