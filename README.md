# Mitsubishi Q시리즈 · GX Works2 PLC/HMI 문서 저장소

Mitsubishi Q시리즈 PLC와 GX Works2를 중심으로 현장 설계, 유지보수, 통신, HMI, 시험 자료를 체계적으로 정리하는 공개 문서 저장소입니다.

## 목표
- PLC 로직과 HMI 화면/알람 자료를 분리해 변경 범위를 명확히 합니다.
- 장비·프로젝트·버전 정보를 기록해 재현 가능한 유지보수를 지원합니다.
- 래더, 파라미터, 통신 설정, 시험 결과를 서로 연결합니다.
- 공개 저장소에 올리면 안 되는 정보는 제외합니다.

## 초기 구조
| 경로 | 목적 |
| --- | --- |
| docs/ | 공통 기준, 프로젝트 색인, 용어, 변경 이력 |
| plc/ | Q시리즈 CPU/모듈, GX Works2, 래더, 파라미터 |
| hmi/ | HMI 화면, 알람/메시지, 태그·주소 매핑 |
| comms/ | MC 프로토콜, 시리얼·Ethernet, 외부기기 연동 |
| tests/ | 시험 계획, I/O 체크, FAT/SAT, 회귀 결과 |
| templates/ | 문서와 시험 기록의 재사용 양식 |

## 권장 추가 순서
1. docs/projects/에 프로젝트 개요와 PLC/HMI 버전을 등록합니다.
2. plc/에 하드웨어 구성, 디바이스 맵, 래더 설명을 추가합니다.
3. hmi/에 화면 목록, 태그 매핑, 알람 목록을 추가합니다.
4. comms/에 통신 토폴로지와 프레임/레지스터 표를 추가합니다.
5. tests/에 시험 항목과 실제 결과를 연결합니다.
6. 반복되는 형식은 templates/로 승격합니다.

## 파일명 규칙
- 영문 소문자와 하이픈 또는 언더스코어를 사용합니다.
- 프로젝트별 자료는 project-id/ 아래에 둡니다. 예: plc/press-line-01/
- 날짜는 YYYY-MM-DD 형식을 사용합니다.
- 버전은 파일명 또는 문서 메타데이터에 명시합니다.
- 제조사 원본 파일은 공개 가능 여부와 라이선스를 확인합니다.

## 공개 전 점검
IP 주소, 계정, 비밀번호, 고객명, 설비 식별정보와 안전 관련 민감정보를 제거합니다.
실제 운전 주소와 예시 주소를 구분합니다.
시험 결과에는 환경, 대상 버전, 판정 기준, 수행일을 남깁니다.

## 문서 상태
draft → review → approved → deprecated

## 라이선스
라이선스와 제조사 문서의 재배포 범위는 저장소 운영자가 별도로 결정합니다.
